# 🎬 Why Perfect Railroads — النسخة البصرية (Remake)

نسخة بصرية **طبق الأصل** (بدون صوت) من فيديو `Why Perfect Railroads Don_t Work(720P_HD).mp4` — مبنية بالكامل على **التحليل الإطار-بإطار** للفيديو الأصلي (1955 إطاراً، 30fps، 720×1280).

## ⚖️ القانونان المقدّسان
1. **كل ما يُبنى يعتمد على التحليل** (الملفات في `analysis/`) — التوقيتات، الألوان، الكاميرا، الترجمة كلمة-كلمة كلها مطابقة للتحليل.
2. **ممنوع الرندر في بيئة المساعد** — الرندر حصراً عبر **Google Colab** (`colab/render_colab.ipynb`) أو workflow_dispatch.

## 🛠️ الأدوات
- **Remotion** — التركيب والرندر (1955 إطاراً بمعدل 30fps)
- **three.js** (`@remotion/three`) — المشهدات ثلاثية الأبعاد (الجسر الجوي f112، السكّة المثالية f1440، جسر الغروب f1784)
- **SVG/CSS** — الشخصيات (Chibi) والمشاهد 2D بأسلوب toon مطابق

## 📁 البنية
```
├── src/
│   ├── theme.ts          # الألوان (k-means) + التوقيتات + الترجمة (186 كلمة/عبارة)
│   ├── Chibi.tsx         # الشخصيات (المهندس/الزعيم/المشرف/...) بنفس أشكال الأصل
│   ├── BuildingBlocks.ts # السماء، الأخدود، القضبان بالمنظور، المحطة، ...
│   ├── scenes2d.tsx      # المشهدات 2D (L01–L40)
│   ├── scenes3d.tsx      # المشهدات three.js
│   ├── Video.tsx         # التايملاين المطابق إطاراً بإطار
│   └── Root.tsx          # Composition: 720x1280, 30fps, 1955 frames
├── colab/render_colab.ipynb  # ⚙️ خلية الرندر (في Colab فقط)
├── analysis/             # التقرير الإطار-بإطار + السجلات الكمية
└── out/                  # 🎥 الناتج: railroads_remake.mp4
```

## ▶️ الرندر (في Colab فقط)
1. افتح `colab/render_colab.ipynb` في Google Colab
2. `Runtime → Run all`
3. عند انتهاء الرندر: النسخة تُحمَّل على الجهاز + في Drive + في هذا المستودع
4. قل للمساعد **"تم"** ليقوم بسحب النسخة وتحليلها
