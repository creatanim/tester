# Why Perfect Railroads Don't Work — إعادة بناء بصرية (بدون صوت)

نسخة بصرية طبق الأصل من الفيديو (720×1280، 30fps، **1955 إطارًا** = 65.167 ثانية) — مبنية بالكامل من التحليل الإطار-بإطار (`analysis/`)، **بدون أي صوت**.

## المحرك (من حزمة animated-shorts المتفوّقة)
عالم ثلاثي الأبعاد مطلي (three.js) + شخصيات كرتونية مرسومة بالكود (bean-head بخطوط حبر) + عمق ميدان + تسميات كلمة-كلمة، تُصيَّر عبر Remotion:

- `src/engine/` — المحرك: `Stage.tsx` (كاميرات + حبر + DOF + تدرّج)، `draw.ts` (رسم الشخصيات)، `Toon.tsx` (بطاقات الشخصيات في العالم 3D)، `kit.tsx` (قطع العالم)، `tex.ts` (نسيج مطلي)، `Captions.tsx` (التسميات).
- `src/rail/cast.ts` — الطاقم: المهندس (قبعة مخططة + تركوازية)، الزعيم (بدلة صفراء + بولر، وبنفسجي عند الغضب)، قائد القطار، رجل الشاي، العمال، مروّج الجرائد، صاحب الكرسي.
- `src/rail/sets.tsx` — البيئات: الأخدود المخطط، النفق + **القاطرة رقم 7**، جسر العوارض فوق الماء، الصحراء، المحطة (القبة + اللافتات)، البهو، حافة العمال، منصة البناء، العربة الفاخرة "VANDERGOLD"، قطارات "RED CANYON LINE"، الفجوات المتوهجة + الفرجار + العملة، السكّة المثالية + كرسي الشاطئ، جسر الغروب، الثعبان، الانفجار + المؤثرات (دخان، شرر، بخار الغضب، كرة نار).
- `src/rail/shots.tsx` — **40 لقطة (L01–L40)** بنفس توقيتات وحركات الكاميرا من التحليل.
- `src/rail/captions.ts` — التسميات كلمة-كلمة (178 مقطعًا) مولّدة من `per_frame_log.csv`.
- `src/rail/Episode.tsx` — الجدول الكامل + التلاشيات المتقاطعة (f405–407، f933–935، f1433–1441، f1778–1783) + الوميض + الويب (9 مرّات).

## التصيير (في Google Colab فقط — القانون المقدس)
دفتر جاهز: `colab/render_colab.ipynb` — الخلايا بالترتيب، ثم الأمر:
```
npx remotion render src/index.ts Railroads out/railroads_remake.mp4 --gl=swangle --concurrency=2 --timeout=300000
```
الناتج: `out/railroads_remake.mp4` — يُحفظ في Google Drive (مجلد "Why Perfect Railroads Remake") + التحميل على الجهاز.
